Predictive Analytics for Employee Mental Health Treatment

Python Machine Learning Predictive Analytics Scikit-learn Random Forest XGBoost Data Preprocessing Data Visualization

Developed a predictive analytics solution to identify factors associated with employees seeking mental health treatment using machine learning. Leveraged the Mental Health in Tech Survey dataset to analyze workplace conditions, employee demographics, and mental health support factors, while comparing multiple classification algorithms to identify the best-performing predictive model.

  • Processed and analyzed the Mental Health in Tech Survey dataset, containing 1,259 records and 27 features, to prepare data for predictive modeling.
  • Performed categorical feature encoding, dimensionality reduction using Principal Component Analysis (PCA), feature standardization, and an 80:20 train-test split.
  • Implemented and compared seven classification algorithms: Logistic Regression, K-Nearest Neighbors, Decision Tree, Random Forest, Gradient Boosting, AdaBoost, and XGBoost.
  • Identified Random Forest as the best-performing model during model comparison, achieving approximately 79% accuracy.
  • Evaluated the selected model using a confusion matrix and classification metrics, achieving 77.78% test accuracy, 73.08% precision, and 89.06% recall.
  • Investigated workplace and employee-related features to support analysis of factors associated with mental health treatment needs.
Outcome: Developed and evaluated a comparative machine learning pipeline for predicting employee mental health treatment-seeking behavior. The project demonstrates end-to-end predictive analytics, from data preprocessing and model selection to performance evaluation, with potential to support workplace mental health awareness.
